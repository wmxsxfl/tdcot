# Experiment Guide

This guide lists the launch commands for the experiments reported in the paper.

All commands assume:

```bash
conda activate tdcot
cd /path/to/tdcot
```

## Environment Variables

```bash
export DATASET_ROOT=/data/datasets
export TIMEBLIND_DATA=/data/datasets/TimeBlind/data.jsonl

export TEMPCOMPASS_PARQUET=/data/datasets/TempCompass/tempcompass_combined.parquet
export TEMPCOMPASS_VIDEO_ROOT=/data/datasets/TempCompass/videos/videos
export TEMPCOMPASS_SETTING=/data/datasets/TempCompass/tempcompass_directionality_items.parquet
export TEMPCOMPASS_JSONL=/data/datasets/TempCompass/tempcompass_directionality_pairs.jsonl

export MVBENCH_DIRECTIONAL=/data/datasets/MVBench/mvbench_directional.jsonl
export MVBENCH_SETTING=/data/datasets/MVBench/mvbench_directionality_setting.jsonl

export AUX_MODEL=/data/models/Qwen2.5-7B-Instruct
export AUX_MODEL_3B=/data/models/Qwen2.5-3B-Instruct
export QWEN_VL_MODEL=/data/models/Qwen2.5-VL-7B-Instruct
export INTERNVL_MODEL=/data/models/InternVL2-8B

export TIMEBLIND_LIMIT=2400
export TIMEBLIND_LIMIT_PAIRS=1200
```

## Build Evaluation Settings

```bash
bash scripts/build_paper_settings.sh
```

This prepares the TimeBlind, TempCompass, MVBench, and router-validation settings used by the launch scripts.

## Directionality Experiments

```bash
bash scripts/run_paper_directionality.sh
```

This stage evaluates Qwen2.5-VL-7B and InternVL2-8B on:

- TimeBlind
- TempCompass directionality pairs
- MVBench directionality subset

Main outputs:

```text
outputs/timeblind_qwen_base.jsonl
outputs/timeblind_qwen_tdcot.jsonl
outputs/timeblind_internvl_base.jsonl
outputs/timeblind_internvl_tdcot.jsonl
outputs/tempcompass_directionality_qwen_base.jsonl
outputs/tempcompass_directionality_qwen_tdcot.jsonl
outputs/tempcompass_directionality_internvl_base.jsonl
outputs/tempcompass_directionality_internvl_tdcot.jsonl
outputs/mvbench_directionality_qwen_base.jsonl
outputs/mvbench_directionality_qwen_tdcot.jsonl
outputs/mvbench_directionality_internvl_base.jsonl
outputs/mvbench_directionality_internvl_tdcot.jsonl
```

## Prompted Baselines

```bash
bash scripts/run_paper_baselines.sh
bash scripts/run_timeblind_baselines_qwen.sh
```

These stages evaluate Generic CoT, Auxiliary-CoT, Localize-then-Answer, TSP, and matched free-form CoT variants according to the method definitions used in the paper.

## Ablations

```bash
bash scripts/run_paper_ablations.sh
```

The ablation launcher evaluates InternVL2-8B on MVB, TC, and TB for:

- full TD-CoT
- w/o temporal segmentation
- 2-state decomposition
- 5-state decomposition
- w/o routing
- free-form CoT with matched reasoning budget
- sequential to joint verification
- w/o conditional prompting
- w/o early exit
- weaker auxiliary LLM

## Router and Statistics

```bash
bash scripts/run_router_and_statistics.sh
```

This stage writes the router validation set, router predictions, threshold sweep, routed-pipeline evaluation, and TimeBlind bootstrap statistics.

## Latency

```bash
bash scripts/run_latency_measurement.sh
```

The latency launcher records end-to-end wall-clock time and ms/query for the main inference methods under a fixed TimeBlind sample limit:

```bash
export LATENCY_LIMIT=100
export LATENCY_LIMIT_PAIRS=50
```

Output:

```text
outputs/latency/latency.csv
```

## General Video QA

```bash
bash scripts/run_paper_general_videoqa.sh
```

The launcher delegates VideoMME-S, VideoMME-L, and MSRVTT-QA to LMMs-Eval. Configure task names for the local LMMs-Eval installation if they differ:

```bash
export VIDEOMME_SHORT_TASK=videomme_short_wo_subtitle
export VIDEOMME_LONG_TASK=videomme_long_wo_subtitle
export MSRVTT_TASK=msrvtt_qa
```

Each LMMs-Eval output directory contains the command manifest and the result files generated by LMMs-Eval.

## Diagnostics

Diagnostic summaries use annotation files under `data/diagnostics/`:

```text
data/diagnostics/decomposition_quality.jsonl
data/diagnostics/holistic_atomic_gap.jsonl
data/diagnostics/failure_taxonomy.jsonl
```

Run:

```bash
bash scripts/run_diagnostics_summary.sh
```

python src/summarize_paper_tables.py --table reference
